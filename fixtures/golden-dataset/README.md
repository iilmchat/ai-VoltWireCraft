# Золотой датасет VoltWireCraft

**Версия:** 0.1 (2026-11-20) · **Связанный дизайн:**
`docs/development/v0.4/DESIGN_V040_COPILOT_3D_GOST_DOCS.md` § 3.1.

Набор из трёх эталонных проектов `.vwc` (`schemaVersion: 2`) для сквозного
тестирования в Docker и регрессионных проверок расчётного ядра, генерации РД
и трёх проекций графа.

> Контрольные значения ниже — ожидаемые инженерные показатели, вычисленные
> по формулам `apps/calc-engine/app/line_sizing.py` и `short_circuit.py`
> с коэффициентом запаса 1,15 и cos φ = 0,95. Допуск: токи и сечения —
> ±5 %, потеря напряжения — ±0,5 процентного пункта. Точные значения
> фиксируются первым успешным прогоном smoke-теста и пересматриваются
> только вместе с изменением справочников ПУЭ.

## Сценарии проверки

1. Загрузить `.vwc` через `POST /projects` и убедиться, что граф проходит
   `ProjectGraphSchema` v2 без миграции.
2. Выполнить `POST /projects/:id/calculate` и сравнить токи и длины с таблицей.
3. Выполнить `POST /projects/:id/ai/audit-pue` и проверить наличие ожидаемых
   замечаний ПУЭ.
4. Сформировать `POST /projects/:id/export/gost-pdf` и проверить состав листов.
5. Для объекта 2 проверить баланс фаз и исполнение вводного УЗО типа `S`.
6. Для объекта 3 проверить, что потеря напряжения на 80-метровой линии
   не превышает 5 %, а кратность срабатывания автомата 32 А выполняется.

## Сквозной smoke-тест в Docker

    docker compose up -d
    pnpm --filter api db:migrate && pnpm --filter api db:seed
    pnpm --filter api exec tsx scripts/smoke-golden-dataset.ts
    docker compose down

Скрипт проходит по всем трём файлам, записывает JSON-отчёт с фактическими
показателями и сравнивает его с контрольными значениями. При расхождении
свыше допустимого отклонения тест завершается с ошибкой.

## Сопровождение

- Новый эталонный объект добавляется только вместе с записью в эту таблицу
  и тестом в `scripts/smoke-golden-dataset.ts`.
- Изменение справочников `PUE_RULES_V02.md` или
  `PUE_SHORT_CIRCUIT_V03.md` требует пересчёта контрольных значений.
- Файлы датасета не редактируются вручную: правки вносятся через приложение
  и экспортируются заново.
