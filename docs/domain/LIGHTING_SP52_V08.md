# Справочник светотехнического расчёта для v0.8.0

**Файл:** `docs/domain/LIGHTING_SP52_V08.md`
**Версия:** 0.1 (стартовая) · **Дата:** 2026-11-20
**Назначение:** нормативные значения освещённости, индекс помещения и
коэффициенты использования светового потока для детерминированного ядра
`calc-engine` и RAG-поиска в `pgvector`.
**Основа:** СП 52.13330.2016 «Естественное и искусственное освещение».
**Связанный дизайн:** `docs/development/v0.8/DESIGN_V080_MCP_LIGHTING_LANDING.md` § 3.2.

> Справочник — рабочая выдержка, а не замена официальному тексту СП 52.13330.
> Значения уточняются по действующей редакции и заданию на проектирование.
> Каждая строка имеет идентификатор для ссылок из протокола расчёта.

---

## 1. Нормативная освещённость по типам зон

| Идентификатор | Тип зоны (`RoomZone.type`) | Норма $E_н$, лк | Примечание |
|---|---|---|---|
| `LIGHT-EN-LIVING` | `living` | 150 | Жилые комнаты, спальни |
| `LIGHT-EN-KITCHEN` | `kitchen` | 150 | Кухня, рабочая поверхность |
| `LIGHT-EN-WET` | `wet` | 100 | Ванная, санузел; уточнять по заданию |
| `LIGHT-EN-UTILITY` | `utility` | 50 | Подсобные, коридоры, кладовые |
| `LIGHT-EN-OUTDOOR` | `outdoor` | 20 | Проходы и территория у дома |

Если тип зоны не задан, ядро возвращает предупреждение и использует
значение `utility` как консервативное.

---

## 2. Площадь помещения и индекс помещения

Площадь многоугольника `RoomZone.polygon` по формуле шнурования (Гаусса):

    S = 1/2 · |Σ (x_i · y_{i+1} - x_{i+1} · y_i)|

где координаты заданы в метрах, а последняя точка замыкается на первую.

Индекс помещения:

    i = S / (h_p · (a + b))

где `h_p` — высота подвеса светильника над расчётной плоскостью, м;
`a`, `b` — длина и ширина помещения, м (для не прямоугольной зоны —
габариты описанного прямоугольника).

---

## 3. Коэффициент использования светового потока $\eta$

Значения приведены для отражения потолка 0,7, стен 0,5 и пола 0,2.

| Индекс помещения $i$ | $\eta$ |
|---|---|
| 0,5 | 0,34 |
| 0,8 | 0,42 |
| 1,0 | 0,47 |
| 1,25 | 0,52 |
| 1,5 | 0,56 |
| 2,0 | 0,62 |
| 2,5 | 0,66 |
| 3,0 | 0,69 |
| 4,0 | 0,73 |
| 5,0 | 0,76 |

Для значения $i$ между строками применяется линейная интерполяция;
вне диапазона — ближайшее граничное значение с предупреждением.

---

## 4. Метод коэффициента использования

Требуемый суммарный световой поток:

    Φ = E_н · S · K_зап / η

Число светильников:

    N = ceil(Φ / Φ_св)

где `K_зап` — коэффициент запаса (по умолчанию 1,1), `Φ_св` — световой поток
одного светильника, лм. Результат округляется вверх; все вычисления
выполняются в `Decimal` (RULES § 5.1).

---

## 5. Протокол расчёта

Ответ `POST /v1/calc/lighting` содержит:

- `areaM2` — площадь зоны, м²;
- `roomIndex` — индекс помещения $i$;
- `utilizationFactor` — коэффициент $\eta$;
- `requiredLumens` — требуемый световой поток $\Phi$, лм;
- `fixtureCount` — число светильников;
- `warnings` — предупреждения (неизвестный тип зоны, выход за диапазон $i$);
- `references` — идентификаторы строк справочника.

Любое числовое значение обязано ссылаться на `references`; языковая модель
не должна вычислять освещённость сама.

---

## 6. Версионирование

При изменении СП 52.13330 создаётся новая версия справочника; чанки в
`pgvector` получают новый `edition`, старые сохраняются для воспроизведения
протоколов. Правка требует обновления тестов и записи в `CHANGELOG.md`
в том же коммите (RULES § 2.1).
