**Назначение:** граничные точки время-токовых характеристик (ВТХ) и алгоритм

## 1. Граничные точки ВТХ

|---|---|---|---|

| `TCC-145` | Тепловая | $1{,}45\,I_n$ | Срабатывает в течение 1 ч |
| `TCC-255-32` | Тепловая | $2{,}55\,I_n$ | 1…60 с при $I_n \le 32$ А |
| `TCC-255-63` | Тепловая | $2{,}55\,I_n$ | 1…120 с при $I_n > 32$ А |

| `TCC-D-HIGH` | Электромагнитная, D | $20\,I_n$ | Срабатывает за ≤ 0,1 с |

| `TCC-ICN-6` | Отключающая способность | 6 кА | Стандартный ряд $I_{cn}$ |
| `TCC-ICN-10` | Отключающая способность | 10 кА | Стандартный ряд $I_{cn}$ |

Гарантированное мгновенное отключение обеспечивается при
$I \ge k_{max}\,I_n$, где $k_{max}$ — верхняя граница зоны (5 / 10 / 20).
Нижняя граница (3 / 5 / 10) — порог, ниже которого мгновенного срабатывания
нет.

## 2. Кусочно-аналитическая модель

    I ≤ 1,13 I_n                  → t = ∞
    1,13 I_n < I ≤ 2,55 I_n       → t = K / ((I/I_n)^2 - 1,13^2)
    2,55 I_n < I < k_min I_n      → t = max(0,1; min(t_тепл; 60))
    I ≥ k_max I_n                 → t ≤ 0,1 с

Постоянная $K = 30$ с подобрана так, чтобы модель проходила через контрольные
точки: при $1{,}45\,I_n$ получается ≈ 36 с, при $2{,}55\,I_n$ — ≈ 5,7 с.
Значения округляются до 3 знаков; вычисления выполняются в `Decimal`.

## 3. Алгоритм расчёта предела селективности $I_s$

Для пары «нижестоящий $d$ / вышестоящий $u$»:

1. Построить логарифмическую сетку токов от $I_n^{d}$ до
   $\min(I_{cn}^{d}, I_{cn}^{u})$ (рекомендуется 200 точек).
2. Для каждого тока $I$ вычислить $t_d(I)$ и $t_u(I)$ по § 2.
3. Проверить условие $t_d(I) + \Delta t \le t_u(I)$, где $\Delta t = 0{,}1$ с.
   Точки с $t_d = \infty$ считаются проходящими.
4. Найти наибольший ток $I_s$, для которого условие выполняется для всех
   токов от нижней границы сетки до $I_s$.
5. Если нарушений нет до верхней границы — $I_s = \min(I_{cn}^{d}, I_{cn}^{u})$
   (полная селективность в пределах отключающей способности).
6. Если условие нарушается уже на первой точке — $I_s = 0$ (селективности нет).
7. Округлить $I_s$ до 3 знаков.

Отдельно проверяется отключающая способность: $I_{cn} \ge I_{кз}$ в точке
установки каждого аппарата. Нарушение фиксируется в `warnings`, но не меняет
$I_s$.

---

## 4. Протокол расчёта

Ответ `POST /v1/calc/selectivity-tcc` содержит:

- `selectivityLimitA` — предел селективности $I_s$ для пары;
- `selective` — булево поле для каждой пары аппаратов;
- `breakingCapacityOk` — результат проверки $I_{cn} \ge I_{кз}$;
- `totalVoltageDropPercent` — каскадная потеря напряжения;
- `warnings` — идентификаторы нарушений;
- `references` — строки этого справочника, использованные ядром.

Поле `references` обязательно для любого числового результата: языковая
модель не должна подставлять значения «от себя» (RULES § 5.1).

## 5. Версионирование

При обновлении ГОСТ Р 50345 или переходе на другую редакцию создаётся новая
версия справочника; чанки в `pgvector` получают новый `edition`, старые
редакции сохраняются для воспроизведения протоколов. Правка требует
обновления юнит-тестов и записи в `CHANGELOG.md` в том же коммите (RULES § 2.1).
