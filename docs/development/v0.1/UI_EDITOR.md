# UI v0.1 — редактор плана VoltWireCraft

**Файл:** `docs/development/v0.1/UI_EDITOR.md`
**Дата:** 2026-11-19
**Статус:** Draft
**Стек:** React 19 · Vite · Konva.js (`react-konva`) · Zustand · Tailwind CSS 4

---

## 1. Назначение

Документ описывает пользовательский интерфейс веб-клиента релиза 0.1:
загрузку подложки, калибровку масштаба, зонирование помещений, расстановку
электроустановочных изделий (ЭУИ) и.Local сохранение проекта в `.vwc`.

Источник истины — `ProjectGraphSchema` из `@voltwirecraft/shared` (RULES § 5.2).
Все геометрические величины в графе хранятся в метрах; масштаб
`floorPlan.scaleMetersPerPx` связывает пиксели подложки с метрами.

## 2. Композиция экрана

| Область | Компонент | Что делает |
|---|---|---|
| Шапка | `Header` | Название проекта, переключатель RU/EN, открыть/сохранить `.vwc` |
| Левая панель | `Palette` | Инструменты, загрузка подложки, палитра ЭУИ (`DevicePlacementTool`) |
| Холст | `FloorPlanEditor` | Слои Konva: подложка → помещения → ЭУИ → инструменты |
| Правая панель | `InspectorPanel` | Свойства выбранного ЭУИ или помещения |
| Наложения | `ScaleCalibratorTool`, `RoomZoneTool` | Формы калибровки и зонирования поверх холста |

## 3. Холст

### 3.1 Навигация

| Действие | Управление |
|---|---|
| Зум к курсору | Колесико мыши; коэффициент `exp(-deltaY · 0,001)`, пределы 0,05–20 |
| Панорамирование | Средняя кнопка мыши или `Space` + левая кнопка + перетаскивание |
| Вписать подложку | Кнопка «Сброс вида» (`tool.resetView`) |
| Удалить выделенное | `Delete` / `Backspace` |
| Отменить незавершённый жест | `Escape` |

Координаты указателя переводятся в координаты подложки формулой
`(pointer - viewport) / viewport.scale`; затем в метры через `scaleMetersPerPx`.

### 3.2 Подложка

- PNG/JPG: файл читается в data URL, изображение decoding через `Image.decode()`.
- PDF: `pdfjs-dist` рендерит выбранную страницу в canvas с масштабом 2,
  результат сохраняется как PNG data URL; worker подключается через Vite `?url`.
- Подложка попадает в нижний `Konva.Layer` и не редактируется напрямую.
- Data URL подложки хранится в графе, поэтому `.vwc` самодостаточен и работает офлайн.

## 4. Инструменты

### 4.1 Калибровка масштаба (`ScaleCalibratorTool`)

1. Выбрать инструмент «Калибровка масштаба».
2. Протянуть отрезок поверх известного размера (например, дверного проёма).
3. Ввести реальную длину в миллиметрах (например, `900`).
4. Применить — в граф пишется `scaleMetersPerPx = (мм / 1000) / длина_пикселей`.

До калибровки используется резервный масштаб 1 пикс = 1 мм; в панели свойств
показывается сообщение «Масштаб не задан».

### 4.2 Зонирование (`RoomZoneTool`)

- Выбрать тип помещения: `living`, `wet`, `kitchen`, `outdoor`, `utility`.
- Кликать по вершинам контура; замыкание — двойной клик, `Enter`, клик по первой
  вершине или кнопка «Применить».
- Полигон сохраняется в метрах, заливается полупрозрачным цветом, подпись
  выводится в центроиде. Минимальная площадь контура — 100 кв. пикс.

### 4.3 Расстановка ЭУИ (`DevicePlacementTool`)

Поддерживаемые kinds: `panel`, `socket`, `switch`, `light_fixture`, `appliance`.

- Клик по кнопке палитры «вооружает» тип, следующий клик по холсту устанавливает ЭУИ.
- Drag-and-drop кнопки палитры на холст (MIME `application/x-vwc-device`).
- В инспекторе редактируются: УГО/название, мощность (Вт), высота установки (м),
  привязка к помещению. Перемещение — перетаскиванием при инструменте «Выбор».

## 5. Файл `.vwc`

```json
    {
        "format": "vwc-project",
        "schemaVersion": 1,
        "graph": { "...": "ProjectGraphSchema" },
        "savedAt": "2026-11-19T00:00:00Z"
    }
```

Экспорт: `ProjectGraphSchema.parse(graph)` → обёртка → Blob → скачивание.
Импорт: `JSON.parse` → `VwcFileSchema.safeParse` → диагностика кода ошибки
(`invalidJson`, `invalidFormat`, `newerVersion`, `olderVersion`, `invalidGraph`).
Версия `schemaVersion > 1` отклоняется с требованием обновить приложение.

---

## 6. i18n

Все видимые строки лежат в `src/i18n/ru.json` и `src/i18n/en.json`. Ключи EN
проверяются на компиляции через `Record<keyof typeof ru, string>`. Новую строку
нельзя использовать напрямую в JSX — только через `t('ключ')`.

---

## 7. Известные ограничения

- Подложка хранится в `.vwc` как data URL; файл проекта может быть крупным.
- Отмена/повтор (undo/redo) и трассировка кабелей в UI 0.1 не реализованы.
- Серверный граф `BackendProjectGraphSchema` (узлы/рёбра) сосуществует с
  клиентским `ProjectGraphSchema` (план/ЭУИ); единая конвертация — задача
  следующего релиза.
